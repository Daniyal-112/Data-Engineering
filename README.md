## 🤔 What is Data Engineering? (in simple words)

Companies collect a lot of data (sales, users, apps, websites). This data is usually messy and stored in many places.

A **Data Engineer** builds systems that:

1. **Collect** data from different sources (files, APIs, databases)
2. **Clean** it (remove errors, duplicates, missing values)
3. **Store** it in an organized way (databases / data warehouses)

So that Data Analysts and AI/ML teams can use it. This process is called **ETL** (Extract → Transform → Load).
